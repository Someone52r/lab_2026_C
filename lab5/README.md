Задание:
прога работает с базой данных сложных объектов.
ТЗ

1. Управление программой полностью чрез текстовое меню в консоли
	например:	1. Вывести список товаров на экран
			2. Добавить новый товар
			Введите номер: |ожидает ввода 1 или 2|

2. Минимальный список действий
	1. Вывод содержимого датабазы
	2. Поиск по массиву хотя бы по 2 параметрам
	3. Добавление новых элементов
	4. Удаление элемента из датабазы
	5. Редактирование элемента из датабазы

3. Хранение датабазы в файле. Текстовый или бинарник - не суть.
	1. Все структуры должны быть объявлены в заголовочном файле, реализация функций в отдельном или нескольких файлах + файл с main
	2. Для сборки использовать Makefile

Тема - бар
